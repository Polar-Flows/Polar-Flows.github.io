# Image Placeholders

This directory contains placeholder images for the Polar Flows website.

## Required Images

### Logo Files
- `logo.svg` - Main logo (already created)
- `logo-dark.svg` - Dark variant logo for dark mode
- `favicon.svg` - Favicon (already created)

### Social Media & SEO
- `og-image.jpg` - Open Graph image (1200x630px)
- `twitter-image.jpg` - Twitter Card image (1200x600px)

### PWA Icons
- `logo-192.png` - 192x192 PWA icon
- `logo-512.png` - 512x512 PWA icon

### Content Images
- `hero-bg.jpg` - Hero section background
- `team-avatar-1.jpg` - Team member avatar
- `team-avatar-2.jpg` - Team member avatar  
- `team-avatar-3.jpg` - Team member avatar

## Image Guidelines

- Use WebP format when possible for better performance
- Provide fallback JPG/PNG versions
- Optimize images for web (compress, resize appropriately)
- Maintain brand consistency with Polar Flows color palette
- Ensure accessibility with proper alt text

## Color Palette

- Primary Blue: #187ef9
- Navy: #012d75
- White: #ffffff
- Slate: #123456
- Azure: #0665d8
- Deep: #0140a8
