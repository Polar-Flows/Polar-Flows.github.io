# Image Assets Structure

This folder contains all image assets for the Polar Flows website.

## Folder Organization

### `/team/`
- Team member profile pictures
- **ProfilePicDanne.jpg** - Daniel Sjoholm's profile picture
- **alex.svg** - Alex Berg placeholder
- **maja.svg** - Maja Lind placeholder  
- **samir.svg** - Samir Khan placeholder

### `/polarflows/`
- Polar Flows brand and company images
- **Polarflows-logo.png** - Main company logo (PNG version)
- **polar-flows-logo.svg** - Main company logo (SVG version)

### `/placeholders/`
- Placeholder images and documentation
- **README.md** - Documentation for placeholder images

### Root level
- **favicon.svg** - Website favicon
- **Main-background.png** - Hero section background image

## Usage Notes

- Team profile pictures should be placed in `/team/` folder
- Company logos and brand assets should be placed in `/polarflows/` folder
- All image paths in the code have been updated to reflect this new structure
- The website will continue to function normally with these changes
