# Partnership Logos

This directory contains logos for technology partnerships displayed on the website.

## Required Logos

The following logo files are needed for the Technology Partnerships section:

- `azure-logo.png` - Microsoft Azure logo
- `aws-logo.png` - Amazon Web Services logo  
- `databricks-logo.png` - Databricks logo (already exists in ../polarflows/)
- `snowflake-logo.png` - Snowflake logo
- `dbt-logo.png` - dbt logo
- `azure-devops-logo.png` - Azure DevOps logo
- `terraform-logo.png` - Terraform logo
- `powerbi-logo.png` - Power BI logo
- `tableau-logo.png` - Tableau logo

## Logo Requirements

- **Format**: PNG with transparent background preferred
- **Size**: At least 200x200px (will be scaled down by CSS)
- **Style**: Official company logos with consistent visual weight
- **Accessibility**: Ensure good contrast and readability

## Notes

- The Databricks logo already exists in the parent polarflows directory
- Logos should be official company logos, not modified versions
- Ensure you have permission to use these logos on your website
- Consider adding alt text descriptions for accessibility
